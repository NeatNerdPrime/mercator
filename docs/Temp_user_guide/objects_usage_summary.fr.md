# Résumé de l’utilisation des objets de Mercator

| Objet Mercator | Représente |
| :--- | :--- |
| Entité | L’entreprise, ses sites, ses services (centraux / usines), ses filiales et bureaux commerciaux, les fournisseurs et les prestataires de manière récursive, les dépôts, les clients. Les comptes et régions cloud |
| Relations | Un lien (autre que de parenté) entre deux entités du SI. Le lien est souvent contractuel / fourniture d’un bien ou d’un service mais pas obligatoirement. |
|  |  |
|  |  |
| Blocs applicatifs | Regroupements d’applications suivant des critères techniques ou fonctionnels |
| Applications | Logiciels de l’entreprise,  Instances de calcul cloud, instances de conteneurs cloud.  Services cloud de base de données, de bureau virtuel, de bureau virtuel applicatif |
